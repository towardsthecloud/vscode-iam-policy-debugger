# AWS IAM Policy Debugger

VS Code extension for debugging IAM policies and saving access scenarios as regression tests.

Scaffold adapted from [AWS IAM Actions Snippets](https://github.com/towardsthecloud/vscode-iam-actions-snippets). Uses ACT Security Labs IAM simulation libraries.

Development: `fnm use`, `npm install`, `npm run compile`.
